# Writing the Introduction Chapter

## Overview

An academic introduction is a **narrowing funnel**: general context → specific gap → thesis/aim → scope. By the end the reader must know **why** the work exists and **what** it will do. Core principle: **placement before assertion** — locate the study inside an ongoing research conversation before claiming a contribution.

## When to use

- Drafting an introduction for a dissertation or research report
- Opening reads journalistic (drama, sides, no citations)
- Lit-review feels like a catalogue, not an argument
- Reader cannot answer "why this study?" at the end
- Aim is stated but not justified, or vice versa
- Paragraph transitions jump rather than narrow

## Quick Reference

| Move | Marker |
|---|---|
| Contextualise | "This class of methods is widely used because..." |
| Sharpen | "More narrowly, the unresolved issue is..." |
| Survey selectively | "Previous work has established X but has usually assumed Y." |
| Identify gap | "However, the effect of Y on Z has received little systematic study." |
| State aim | "This dissertation examines how Y affects Z under controlled conditions." |
| Foreshadow | "Chapter 2 reviews...; Chapter 3 introduces the methodology..." |

**Reporting verbs:** neutral (*describe, examine, apply*); stance (*argue, propose, contend, suggest*); evaluative (*overlook, assume, conflate, neglect*).

**Hedging (mandatory for empirical claims):** use the hedging ladder in [`academic-english-style`](../academic-english-style/SKILL.md). Avoid bare assertions like "the intervention always improves accuracy" — empirical behaviour is usually regime-dependent.

## Core moves

1. **Sentence 1 = anchored context, not drama.** Cite a long-running problem; no headlines.
2. **Each sentence narrows.** If deleting it doesn't change the focus, it is filler.
3. **Selective, critical lit review.** Cite to build the gap, not to show reading. One sentence per work.
4. **Gap before aim.** Justify before announcing.
5. **End with aim + scope + foreshadowing** ("In this dissertation I…", "Chapter X examines…").
6. **Hedged but committed.** Claim + condition: "under the tested setting, method A exhibits measurable drift relative to method B".

## Common Mistakes

| Symptom | Fix |
|---|---|
| Opens "Imagine a rocket re-entering..." | Replace with citation-anchored field problem |
| Lit review lists every Riemann-solver paper | Cut to works that motivate the gap |
| Aim in sentence 1 | Move aim to end, after context + gap |
| "The intervention is faster and more accurate" (unhedged) | Add regime, measurement, and problem class |
| Abrupt topic jumps | Use *however, in particular, more narrowly, consequently* |
| Reader asks "so what?" | Add "without this, X cannot be determined" |

## Worked example (annotated funnel)

> **[1 Context]** The method studied in this dissertation is widely used because it gives stable results on a class of difficult problems. **[2 Sharpen]** Its accuracy has, however, usually been evaluated under a simplifying assumption about the computational setting. **[3 Survey + tension]** Recent work on related methods suggests that this assumption may affect both accuracy and reproducibility. **[4 Gap]** Yet the sensitivity of this method to the assumption remains, to our knowledge, without systematic characterisation. **[5 Aim]** This dissertation therefore investigates how the assumption affects accuracy and stability on a controlled set of test cases. **[6 Foreshadow]** The following chapters review the theory, define the methodology, present the results, and discuss their implications.

Notes: (1) cites rather than dramatises; (2)–(4) each narrow; (4) hedges but is specific; (5) is committed but methodology-conditioned; (6) foreshadows without spoiling results.
