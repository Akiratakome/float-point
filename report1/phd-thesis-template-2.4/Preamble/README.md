# Preamble Directory

`preamble.tex` is the single place for Report 1 package and formatting changes.

Current report-facing packages include:

- `caption` and `subcaption` for figures.
- `booktabs` and `multirow` for tables.
- `siunitx` for units and numeric formatting.
- `enumitem` for list spacing and control.

Do not add packages in chapter files unless a package is demonstrably local to a
single imported appendix or external fragment.
