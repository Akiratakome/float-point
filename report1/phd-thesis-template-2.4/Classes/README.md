# Classes Directory

This directory contains the CUED template class files.

- `PhDThesisPSnPDF.cls` is vendor template code.
- `glyphtounicode.tex` is loaded by the class for PDF text extraction support.

Treat these files as stable infrastructure. Prefer changing `thesis.tex`,
`thesis-info.tex`, or `Preamble/preamble.tex` before editing the class.
