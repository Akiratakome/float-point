# Report 2 writing-skill routing

The writing skills are shared with Report 1 to avoid duplicated instructions.
Use their files under `report1/skills/`; Report 2-specific scientific scope is
defined by `report2/planning/manuscript_outline.md` and the evidence map.

| Task | Primary skill | Optional companion |
|---|---|---|
| Introduction | `writing-introduction` | `academic-english-style` |
| Focused literature/transition | `writing-literature-review` | `academic-english-style` |
| Development and methodology | `scientific-writing-duke` | `academic-english-style` |
| Validation/results | `scientific-writing-duke` | `academic-english-style` |
| Discussion | `scientific-writing-duke` | `academic-english-style` |
| Conclusion | `writing-conclusion` | `academic-english-style` |
| Line editing | `editing-academic-prose` | then `avoiding-ai-flavor` |

Use at most two skills in one drafting pass. `avoiding-ai-flavor` is a mandatory
acceptance gate for every AI-assisted paragraph, not a licence to submit it.

For Report 2 Chapter 4 specifically, use Report 1 Chapters 5 and 6 as the
language corpus and Chapter 4 only for terminology continuity. The required
sequence is:

1. draft with `scientific-writing-duke` + `academic-english-style`;
2. revise structure with `editing-academic-prose`;
3. run `avoiding-ai-flavor` as a separate acceptance pass;
4. have the student rewrite and fact-check the resulting English.

Do not load `report1-context` for Report 2 work: it carries Report 1 scope and
word-count constraints. Report 1 prose is a voice/structure reference only;
Report 2 claims must come from its outline, evidence map, and reference map.
